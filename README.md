# Mike Becker Portfolio Site

## To update the site

1. Open `content/site.txt` directly on GitHub.
2. Click the pencil icon, edit the values, click Commit changes.
3. Site updates in ~1 minute.

To swap a video: drag the new file into the matching folder under `media/` on GitHub. Commit. Done.

## Folder layout

```
mike-becker-site/
├── index.html
├── content/
│   └── site.txt          EDIT THIS FILE to change site values
├── media/
│   ├── reel/
│   │   ├── reel.mp4      Hero reel
│   │   └── poster.jpg    First frame of the reel (for the intro)
│   ├── tile-1/           Drop tile 1 video here, named tile-1.mp4
│   ├── tile-2/           Drop tile 2 video here, named tile-2.mp4
│   ├── tile-3/
│   ├── tile-4/
│   ├── tile-5/
│   └── tile-6/
```

## Video size limits

- Each video file under 25MB
- 1920x1080 max resolution
- H.264 MP4 recommended
