# Each project has its own block below. The fields per block are:
#
#   WORK_N_FILE  = hover-loop video filename (3-5 seconds)
#   WORK_N_FULL  = full project video filename (plays in lightbox)
#   WORK_N_TITLE = project name (shown on the tile)
#   WORK_N_ROLE  = section the project belongs to. Must be exactly one of:
#                    Director           (label on the site: "Director")
#                    Specialty Camera   (label on the site: "Specialty")
#                    Operator           (label on the site: "Camera")
#   WORK_N_WIDE  = optional. "true" makes this project the hero of its
#                  section. Only one project per section should be WIDE.
#   WORK_N_ORDER = optional integer. Controls position within section.
#                  Lower numbers appear first. If unset, defaults to N
#                  (the slot number), giving the legacy behavior of
#                  numeric ordering. Useful when you want projects to
#                  appear in a different order than their slot numbers.
#
# FOLDER RULE:
#   Project N's video files live in media/work-N-SECTION/
#   where SECTION is "director", "specialty", or "camera"
#   matching the project's ROLE field above.
#
#   Examples:
#     WORK_1_ROLE = Director           → folder is media/work-1-director/
#     WORK_4_ROLE = Specialty Camera   → folder is media/work-4-specialty/
#     WORK_9_ROLE = Operator           → folder is media/work-9-camera/
#
#   FILE and FULL values are just the filename (no slashes, no path).
#
# TO ADD A NEW PROJECT:
#   1. Pick the next available slot number (next free N).
#   2. Decide its section (Director / Specialty Camera / Operator).
#   3. Make folder: media/work-N-SECTION/ matching the section slug.
#   4. Put two .mp4 files in that folder.
#   5. Add a WORK_N block here with all four required fields.
#   6. Commit and push.
#
# TO MOVE A PROJECT TO A DIFFERENT SECTION:
#   1. Change WORK_N_ROLE to the new section value.
#   2. Rename media/work-N-OLD/ to media/work-N-NEW/ so the suffix matches.
#   3. Commit and push.
#
# TO REMOVE A PROJECT:
#   Delete or comment out its block here. The folder can stay or be
#   removed.
#
# SECTION LAYOUTS (4 projects per section, all sections currently full)
#
#   Director (4 projects, 3 rows of varying size):
#     1st: hero (12 wide, 2.39:1 cinemascope opener)
#     2nd: three-quarter (9 wide, full 16:9)
#     3rd: quarter (3 wide, 16:27 — sides crop ~33%)
#     4th: hero closer (12 wide, 2.39:1)
#
#   Specialty (4 projects, 2 rows):
#     1st: hero (12 wide, 2.39:1)
#     2nd: small (3 wide, ~8:9 — sides crop ~50%)
#     3rd: half (6 wide, full 16:9)
#     4th: small (3 wide, ~8:9 — sides crop ~50%)
#
#   Camera (4 projects, 3 rows):
#     1st: hero (12 wide, 2.39:1)
#     2nd: half (6 wide, full 16:9)
#     3rd: half (6 wide, full 16:9)
#     4th: hero (12 wide, 2.39:1)
#
# The position of each project within its section is determined by:
#   - Whichever project has WIDE=true becomes the hero (slot 1).
#   - The remaining projects fill slots 2, 3, 4 in numeric order
#     (lowest WORK_N first).
#
# Small tiles crop the source video to roughly its center 50%.
# Put centered subjects, close-ups, or tight compositions in those slots.
# Put wide landscapes and ensembles in the hero or half slots.
