# Each project on the Work page has its own block below.
# Only blocks with all four required fields filled in render on the page.
# Empty / commented-out blocks are skipped entirely (no empty tiles).
#
# WORK_N_FILE  = hover loop video
# WORK_N_FULL  = full project video (lightbox)
# WORK_N_TITLE = project name
# WORK_N_ROLE  = your credit on this project. Must be one of:
#                  Director
#                  Specialty Camera
#                  Operator
#                Projects are grouped into sections on the work page
#                by role, in the order above.
# WORK_N_WIDE  = optional. Set to "true" to make this tile the
#                section's HERO — the cinematic full-width tile.
#                Use it on your strongest piece per section. If no
#                WIDE flag is set in a section, the first project
#                listed in that section becomes the hero by default.
#
# SECTION LAYOUT (4 tiles per section)
#
# Specialty Camera and Operator share the same macro structure:
# one cinematic hero opener, then a single cluster row with three
# tiles at smaller scale. The cluster is one HALF (6/12 width,
# full 16:9 frame) + two SMALL tiles (3/12 width, ~8:9 cropped).
# Heights match exactly so the row fills with no whitespace.
#
# Director is the exception. Director uses all-large tiles —
# hero opener, a pair of halves in the middle, and a second hero
# closer at the bottom. No small accents in Director.
#
# The position of the cluster's half tile in SC and Operator
# differs by section so each section's row 2 has a distinct
# silhouette:
#
#   Director (large opener + asymmetric pair + large closer)
#     tile 1: hero (12 wide, 2.39:1 cinemascope opener)
#     tile 2: three-quarter (9 wide, full 16:9 — takes 3/4 of
#             the middle row's length)
#     tile 3: quarter (3 wide, 16:27 portrait-ish — takes the
#             remaining 1/4 of the middle row; the 16:9 video
#             crops to roughly the center 33% horizontally)
#     tile 4: hero closer (12 wide, 2.39:1 — second cinematic
#             anchor at the bottom of the section)
#
#     Director deliberately uses all-large tiles. The next section
#     (Specialty Camera) also opens on a hero, so the transition
#     between sections will have two large tiles back-to-back.
#     This is an intentional design choice for Director only.
#
#   Specialty Camera (currently only 2 populated tiles)
#     tile 1: major (Ford Bronco, 8 wide, 16:9 — dominant
#             landscape with WIDE flag)
#     tile 2: minor (CRACKED, 4 wide, 8:9 — supporting tile
#             beside Ford, 16:9 source crops to center ~50%)
#
#     Single-row asymmetric pair. Adding a 3rd or 4th SC project
#     switches it to a larger layout automatically.
#
#   Operator (cluster anchor RIGHT — 4 tiles)
#     tile 1: hero (Rab — NetPlus x Microlight, 12 wide, 2.39:1)
#     tile 2: small (3 wide, ~8:9 — accent, sides crop ~50%)
#     tile 3: small (3 wide, ~8:9 — accent, sides crop ~50%)
#     tile 4: half (6 wide, full 16:9 — strongest non-hero piece)
#
# The small tiles crop their video to roughly the center 50%
# horizontally. Put centered subjects, close-ups, or tightly-
# framed shots in the small slots. Put wide landscapes and full
# ensemble shots in the hero or half slots where the full frame
# is preserved.
#
